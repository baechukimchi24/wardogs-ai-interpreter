# WARDOGS AI Interpreter v0.9 — 한국어 설치·사용 설명서

## 무엇이 바뀌었나요?

**자막 출력이 최우선**입니다. v0.8에서 연속 영어 대사가 인식돼도 번역이 밀리거나 `[한국어 번역]` 같은 자리표시자가 나오는 문제를 줄이기 위한 개선입니다.

- **연속 발화 자막 밀림 자동 완화(기본 ON)**: 문장이 대기열에 쌓이면 다음 처리 문장을 빠른 Argos 번역으로 우회합니다. 그 결과 실시간성이 좋아질 수 있지만 슬랭 번역 품질은 일부 낮아질 수 있습니다.
- 번역 모델에 **한국어 자막만** 요청합니다. 추천 답변을 동시에 생성하지 않습니다.
- **영어 답변 추천 표시**는 별도의 ON/OFF 체크박스이며 **기본 OFF**입니다. ON에서는 짧은 게임 상황별 규칙으로 추천하므로 번역 LLM 추론 시간을 사용하지 않습니다. 추천 TTS는 버튼을 눌러야만 선택한 장치로 송출됩니다.
- 인식된 영어 문장 번역 대기열은 128개까지 보관하고 **오래된 문장을 조용히 지우지 않습니다.** 번역이 밀리면 '자막 번역 대기 N개'가 표시됩니다. 단, 음성 인식 대기열(오디오 클립 16개)이 가득 차는 극단적 상황에서는 오래된 클립이 폐기될 수 있고 화면에 횟수를 알립니다.
- GGUF LLM이 응답을 못 하거나 `[한국어 번역]` 같은 자리표시자만 반환하면 **Argos 오프라인 번역으로 대체**합니다. 기본 설치에서 Argos 모델이 설치되어 있어야 대체가 가능합니다.
- 최소 음성 길이 기본 **150ms**, 말 끊김 종료 대기 기본 **300ms**; 앱에서 ms 값을 조절·저장할 수 있습니다. WebRTC VAD의 30ms 프레임 경계로 올림됩니다. 발화 시작 감지는 별도로 90ms 연속 음성 판정입니다.
- 기존 'No', 'Go', 'OK' 등 짧은 영어가 3자 미만이라 무조건 폐기되던 조건을 제거했습니다.
- 모델 선택: 기존 Qwen3 4B, Qwen3.5 4B, EXAONE 3.5 2.4B에 더해 **Qwen3.5 2B / 0.8B**, 그리고 **OPUS-MT 영어→한국어 CPU 번역**을 추가했습니다.
- VAC `Line 1`, 전역 오버레이 단축키(F10), 한국어 TTS 기본 OFF, Windows 프로세스별 게임 오디오 수집은 그대로 유지합니다.

## 1. 새로 설치하기 — Visual Studio 불필요

**대상:** Windows 11 64비트. ZIP 안에 Windows x64 `bin/process_loopback.exe`가 포함되어 있습니다. Visual Studio, Ollama, 시스템 Python 설치는 필요 없습니다.

1. 압축을 풀어 `INSTALL_AND_START.bat`, `START.bat`, `bin`, `tools`, `main.py`가 한 폴더에서 보이게 합니다. 권장 경로는 `C:\wardogs_interpreter`입니다. 다른 폴더여도 됩니다.
2. **`INSTALL_AND_START.bat` 더블클릭**. 인터넷으로 프로젝트 전용 Python 3.11, Python 라이브러리, Argos 영어→한국어 모델을 자동 구성합니다. 추가적인 OPUS-MT 라이브러리(Transformers)도 설치하지만 OPUS 모델 가중치는 받지 않습니다.
3. 설치 성공 후 프로그램이 자동 실행됩니다. 이후에는 `START.bat`을 사용하세요.
4. 모델 다운로드 및 음성 인식 최초 사용 시에도 인터넷 연결이 필요합니다. NVIDIA GPU/Whisper 가속은 적절한 CUDA/cuDNN 런타임이 추가로 요구될 수 있습니다. 가속이 불가능하면 Whisper가 CPU 모드를 시도합니다.

**기존 v0.8에서 교체할 때:** 반드시 통역 프로그램을 종료한 다음 새 ZIP의 파일을 압축 해제하세요. 새 설치를 추천하지만 이전 모델을 유지하려면 `models`·`engines`·`.venv`를 삭제할 필요는 없습니다. 새로 추가된 의존성 설치를 위해 **`INSTALL_AND_START.bat`을 다시 실행**하세요. 다른 프로그램이 현재 오디오 장치를 사용해도 시스템 기본 출력이나 마이크 라우팅은 변경하지 않습니다.

## 2. 번역 모델 선택과 다운로드

### A. 가장 빠르게 시험: Argos

번역 방식을 **`Argos (offline)`**으로 선택하고 `번역 UI 데모`를 누르세요. 별도 엔진 다운로드/적용 버튼은 필요 없습니다. 영어→한국어 전용이라 짧은 게임 은어는 오역할 수 있습니다.

### B. 새로운 작은 Qwen3.5 모델 (GGUF)

1. 번역 방식을 **`Local GGUF (offline)`**으로 선택합니다.
2. 모델 드롭다운에서 **`Qwen3.5 2B (Q4_K_M)`** 또는 **`Qwen3.5 0.8B (Q4_K_M)`**를 고릅니다. 2B는 약 1.28GB, 0.8B는 약 0.5GB의 모델 파일입니다. 실제 VRAM/RAM 사용량은 파일 크기보다 더 클 수 있습니다.
3. 실행 방식은 처음에 **`CUDA GPU 일부 사용 (8 레이어)`** 또는 **`Vulkan GPU 일부 사용 (8 레이어)`**을 시험하세요. 더 빠른 자막이 필요하면 `CUDA/Vulkan 16 레이어`도 선택해 비교하세요. 일부 GPU 사용이 항상 최적 속도를 보장하는 것은 아닙니다. 게임 종료 상태에서 전체 GPU 모드 성능을 비교할 수 있습니다.
4. **`선택 모델 + 엔진 준비 (원클릭)`**을 눌러 현재 엔진과 모델을 받습니다.
5. 설치 상태가 준비됨으로 바뀌면 **`선택 모델 적용 및 번역 검증`**을 누릅니다. 실제 짧은 영어 문장을 한국어로 번역해 적용 성공을 확인합니다.
6. 이어서 **`번역 UI 데모`**를 실행합니다. 첫 모델 로딩에는 시간이 걸릴 수 있습니다.

Qwen이 `[한국어 번역]` 등 틀린 출력을 보이면 프로그램은 이를 무효로 처리하고 Argos로 대체를 시도합니다. LLM 번역 자체가 빨라진다는 보장은 없습니다. 8레이어만 사용하면 나머지 추론이 CPU에서 수행되어 병목이 생길 수 있습니다.

### C. OPUS-MT (CPU, 영어→한국어 전용)

1. **`OPUS-MT 경량 번역 모델 다운로드 (CPU)`** 버튼을 눌러 약 420MB 모델을 받습니다.
2. 번역 방식을 **`OPUS-MT (offline)`**으로 변경합니다.
3. **`번역 UI 데모`**를 누릅니다. OPUS-MT는 GGUF 모델이 아니므로 llama.cpp 엔진/모델 적용 버튼이 필요 없습니다.
4. 전용 번역 모델인 만큼 게임 슬랭은 Qwen/EXAONE과 정확도가 다를 수 있습니다. 게임 중 FPS를 유지하려면 CPU 사용률도 확인하세요.

| 모델 | 다운로드 파일 대략 | 특징 |
|---|---:|---|
| Argos 영어→한국어 | 최초 설치에 포함 | 안정적인 대체 번역 |
| Qwen3.5 0.8B Q4 | 0.5GB | 최경량 LLM, 정확도는 실측 필요 |
| Qwen3.5 2B Q4 | 1.28GB | 경량·품질 균형 후보 |
| EXAONE 3.5 2.4B Q4 | 1.64GB | 한국어 표현 비교용, 라이선스 확인 |
| Qwen3.5 4B Q4 | 2.7GB | 기존 품질 우선 비교용 |
| OPUS-MT en→ko | 0.42GB | CPU 전용 번역 모델 |

## 3. 실시간 음성 감지 설정

- **음성 감지 민감도**: 0(민감) / 1 / 2 / 3(소음 억제). 음성이 누락되면 우선 1로 내려보세요.
- **최소 음성 길이**: 기본 150ms, 60~900ms 조정. 너무 낮으면 총소리·게임 효과음의 오인식 가능성이 커집니다.
- **음성 종료 대기**: 기본 300ms, 150~1200ms 조정. 낮으면 응답이 빨라질 수 있지만 연속된 말이 지나치게 짧게 분리될 수 있습니다. 긴 문장이 잘린다면 450~600ms로 올리세요.
- **Whisper 모델**: `small.en` 권장. 음성이 너무 누락되거나 GPU 부담이 크면 `base.en`도 비교해 보세요.

위 ms 설정은 번역 **시작 시 적용**됩니다. 변경한 뒤 통역을 중지하고 다시 시작해야 새 음성 감지 조건에 확실히 반영됩니다.

## 4. 자막 우선 및 추천 답변 ON/OFF

- **연속 발화 Argos 빠른 대체**는 기본 ON입니다. 끄면 선택한 번역 모델만 사용하지만 대사가 몰릴 때 지연이 길어질 수 있습니다.
- **영어 답변 추천 표시**는 기본 OFF입니다. ON으로 변경하면 인식된 영어 문장에 대해 세 가지 짧은 응답이 나옵니다. 규칙 기반 추천이라 모델 추론 자원을 점유하지 않습니다. ON/OFF는 실행 중 변경할 수 있습니다.
- 버튼을 직접 눌러야만 선택한 **영어 TTS 출력 장치**로 송출됩니다. VAC Muzychenko `Line 1 (Virtual Audio Cable) [Windows WASAPI]`를 선택할 수 있습니다. 기존 마이크, 오디오 인터페이스, 윈도우 기본 입력·출력을 바꾸지 않습니다.
- **한국어 실시간 TTS**는 기본 OFF입니다. 별도 출력 장치를 선택해 켤 수 있습니다.
- **자막 오버레이**는 기본 F10 단축키로 ON/OFF가 가능하며, 앱에서 변경할 수 있습니다. 게임의 테두리 없는 창 모드를 권장합니다. 안티치트 허용 여부는 보장되지 않습니다.

## 5. 실제 게임 시험 순서

1. `START.bat` → Argos `번역 UI 데모`가 정상 한국어 출력하는지 확인
2. GGUF/OPUS 중 희망 모델 다운로드 → **실제 번역 데모** 확인
3. `영어 송출 테스트`로 본인이 선택한 VAC 출력 채널 확인 (연결된 게임에 실제 송출될 수 있음)
4. WARDOGS 실행 → `프로세스 새로고침` → `번역 시작`
5. 빠르게 연속으로 영어가 들릴 때 영어 원문과 한국어 자막이 모두 나타나는지 확인
6. `한국어 자막 번역 대기: N개 문장` 메시지가 자주 보이면 더 작은 모델/Argos/OPUS-MT로 전환해 테스트
7. RTX 5070 Ti 게임 FPS와 CPU/GPU 점유율을 비교 (144FPS 유지는 환경에 따라 달라짐)

**주의:** 인식된 텍스트를 대기열에 보관해 누락을 줄였지만, Whisper가 아예 단어를 인식하지 못하는 경우와 오디오 클립 대기열이 포화되는 극단적 상황까지 완벽하게 복구하지는 못합니다. 자동 Argos 대체도 Argos 모델 설치가 성공한 경우에만 가능합니다.

## 6. 라이선스·배포·개인정보

- 다운로드 모델은 ZIP에 포함되지 않습니다. 사용자는 모델 페이지에서 라이선스를 확인해야 합니다. Qwen3.5는 Apache 2.0 모델, OPUS-MT는 CC BY 4.0입니다. EXAONE 3.5는 연구·비상업적 사용 조건이 있으므로 모델/가중치를 무단 재배포하지 마세요.
- Google 온라인·OpenAI를 선택하면 인식된 영어 대사가 외부로 전송됩니다. 로컬 GGUF·Argos·OPUS-MT 모드에서는 번역 요청을 외부 API에 보내지 않습니다. 모델 다운로드 때만 인터넷을 사용합니다.
- Windows Process Loopback으로 `WardogsClient-Win64-Shipping.exe`의 게임 소리를 수집합니다. 게임 오디오에 효과음/음성채팅이 함께 포함될 수 있으며 VAC Line 1을 입력 캡처로 사용하지 않습니다.
- 프로그램은 안티치트 우회, DLL 주입, 게임 메모리 열람을 하지 않습니다. 다만 제3자 프로그램 사용이 안티치트 정책상 허용되는지는 사전에 보장할 수 없습니다.
- Windows 11 및 GPU 환경에 따른 추론 속도, 오디오 수집, TTS 출력은 사용자 PC에서 실측 검증이 필요합니다.

## 7. 문제 발생 시

- 설치: `install.log`
- llama.cpp 오류: `logs\llama-server.log`
- 엔진 상태: 화면의 CPU/CUDA/Vulkan 준비 여부 및 모델 적용 결과
- 연속 자막 번역 문제: 오류 메시지, 모델명, 연속된 영어 원문, 한국어 자막 상태를 기록해 보내주세요. 실제 음성 대화나 API 키가 로그에 남지 않았는지 공유 전에 확인하세요.
- OPUS-MT는 처음 실행 때 CPU에 모델을 로딩하므로 첫 데모는 느릴 수 있습니다.

**이 패키지는 v0.8이 사용자 PC에서 동작했던 Windows 오디오 캡처 실행 파일을 유지하고, Python 번역·대기열 로직을 개선한 v0.9 테스트 빌드입니다. Windows 실기에서 신규 경량 모델 및 OPUS 번역은 아직 검증되지 않았습니다.**
