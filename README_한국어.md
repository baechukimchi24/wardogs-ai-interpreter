# WARDOGS AI Interpreter v1.1 Beta

Windows 11을 위한 비공식 게임 영어→한국어 실시간 자막 도구입니다. **v1.1은 오인식 필터, 긴 한국어 오버레이 자막의 페이지 분할, 창 크기 변경에 대응하는 탭 UI를 추가한 베타 소스/EXE 빌드 버전**입니다.

> 이 패키지의 소스 코드는 검사했지만 v1.1 Windows 실기 실행 및 WARDOGS 안티치트 호환성은 아직 검증되지 않았습니다. GitHub Actions에서 EXE를 생성하고, 사용자가 테스트한 다음 공개 배포하세요.

## 무엇이 달라졌나요?

- `Game voice chat.` 등 음성 인식기의 대표적인 효과음 오인식 문구를 **번역 전에 차단**합니다. 기존 Whisper 초기 힌트에 포함된 `Game voice chat.` 문구도 제거했습니다.
- `Fire!`처럼 **정확히 한 단어**인 경우만 선택적으로 제외합니다. 실제 사람이 외친 `Fire!`도 제외될 수 있으므로 **기본 설정 · 자막 → 오인식 필터**에서 해제할 수 있습니다. `Fire in the hole!`, `Friendly fire!` 같은 다른 문장은 자동 차단하지 않습니다.
- 사용자가 제외할 문장을 한 줄씩 입력할 수 있습니다. 대소문자와 문장 끝 문장부호는 무시하며, 문장 **일부분**만 포함된 경우에는 차단하지 않습니다.
- 10초 안에 똑같은 3단어 이하 문장이 세 번 이상 반복되면 세 번째부터 제외할 수 있습니다(기본 ON). 실제 반복 교신도 일부 제외될 수 있습니다.
- 게임 오버레이의 **높이는 110px로 유지**됩니다. 영어는 한 줄로 작게 축약하거나 숨길 수 있고, 긴 한국어는 2줄씩 순서대로 표시하여 텍스트가 끝에서 잘리지 않게 합니다. 긴 한국어의 전체 원문은 언제나 대화 기록에 남습니다. 아주 긴 자막은 여러 페이지에 걸쳐 보이므로 표시시간이 늘어나고, 대사가 많이 몰리면 대기 표시가 발생할 수 있습니다.
- `실시간 대화`, `기본 설정 · 자막`, `AI 모델 관리` 탭을 만들었습니다. 기본적으로 대화 탭이 표시됩니다. 창 크기에 따라 컨트롤 너비가 바뀌며 설정 화면은 세로 스크롤로 접근합니다.
- 기존 Whisper, Local GGUF, Argos, OPUS-MT, VAC 출력, 한국어 TTS 스위치, 답변 추천, F10 자막 토글을 유지했습니다.

## 이미 v1.0 무설치 EXE를 사용 중이라면

현재 작동 중인 v1.0 폴더를 먼저 백업하세요. v1.1 빌드의 EXE가 정상 작동하는지 확인하기 전까지 기존 Release를 삭제하지 마세요.

이번 ZIP은 **완성된 EXE가 아닌 GitHub Actions에서 Windows EXE를 빌드하기 위한 전체 소스 패키지**입니다. PyInstaller가 설치된 GitHub Windows 환경에서 EXE가 만들어집니다. Windows 실행 파일 `bin/process_loopback.exe`가 프로젝트에 포함되어 있으므로 최종 사용자는 Visual Studio Build Tools가 필요하지 않습니다.

1. GitHub 저장소에 ZIP **내용물**을 올립니다. 프로젝트의 `main.py`, `runtime.py`, `speech_filter.py`, `subtitle_layout.py` 등이 저장소 최상위에 보여야 합니다.
2. `.github/workflows/windows-portable.yml` 파일을 올바른 경로에 둡니다.
3. Actions → **Build Windows Portable EXE** → **Run workflow**를 실행합니다.
4. 초록 체크가 표시되면 실행 기록 하단의 Artifacts에서 ZIP을 받습니다.
5. 사용자 PC의 별도 폴더에 풀고 `WARDOGS Interpreter.exe`를 더블클릭합니다.
6. 이미 다운로드한 모델을 재사용하려면 기존 배포 폴더의 `models`, `engines`를 새 배포 폴더로 **복사**하면 됩니다. (기존 파일은 테스트 완료 전 삭제하지 마세요.)
7. `번역 UI 데모`, 실제 게임 캡처, 자막 오버레이, 영어 TTS 장치를 순서대로 확인하세요.

새 환경에서는 EXE를 실행한 후 필요한 AI 모델과 엔진을 프로그램에서 다운로드하세요. 무설치 EXE라서 **파일 하나만 따로 복사하면 안 됩니다.** ZIP 내 `_internal`, `bin` 등 폴더를 유지해야 합니다.

## 처음 추천하는 설정

- **실시간 대화**: 게임 실행 후 프로세스가 인식되면 `번역 시작`.
- **기본 설정 · 자막**: 최소 음성 길이 150~200ms, 음성 종료 대기 240~300ms를 기준으로 상황에 맞게 조절.
- **오인식 필터**: `Game voice chat.` 기본 차단, 단독 `Fire!` 차단 ON, 반복 오인식 감지 ON. 정상 영어까지 차단되면 옵션을 끄고 재시작.
- **영어 원문 표시**: `영어 자동 축소 + 한 줄 축약` 추천. 한국어만 보려면 `영어 숨기고 한국어만 표시`.
- **AI 모델 관리**: Qwen3.5 2B와 CUDA 일부 레이어부터 품질·FPS·속도를 비교. 번역 모델 적용 및 번역 검증 버튼으로 먼저 확인.
- **영어 답변 추천·한국어 TTS**: 자막 우선 사용 시 둘 다 OFF 추천.

## 제한사항 및 주의사항

- 일부 소음이 음성으로 오인식될 수 있습니다. 오인식 필터는 **텍스트를 사후 제외**하는 기능이지 실제 사람 목소리만 완벽하게 분리하는 시스템이 아닙니다.
- 자막 오버레이 높이를 고정했기 때문에 긴 번역은 화면에서 여러 번 바뀌어 표시됩니다. 표시 중 후속 대사가 몰리면 화면 반영이 지연될 수 있습니다.
- EXAONE 모델은 라이선스의 연구/비상업 제한을 확인한 뒤 사용하세요. 모델 파일은 기본 배포 ZIP에 포함되지 않습니다.
- 타사 라이브러리 라이선스는 `licenses/`와 각각의 공식 배포 자료를 확인하세요.
- WARDOGS 개발사의 공식 프로그램이 아니며 안티치트 호환성을 보증하지 않습니다. 게임 메모리 접근이나 DLL 주입은 하지 않도록 작성되어 있습니다.
- 프로그램이 접근하는 게임 음성은 사적인 대화일 수 있습니다. 번역 방식에 따라 외부 서비스로 전달될 수 있으므로 개인 정보와 약관에 유의하세요.
- 개발 환경은 Windows가 아니므로 새 v1.1 GUI·포터블 EXE의 실제 Windows 동작은 검증하지 못했습니다. Python 단위·회귀 테스트와 구문 검사를 진행했습니다.

### 문제 신고 시

`logs/app-error.log`와 오류 메시지, Windows 버전, GPU, 사용 모델, 번역 모드를 알려주세요. 개인 대화, API 키 등 민감한 정보는 제거하세요.
